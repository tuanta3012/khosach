HƯỚNG DẪN KỸ THUẬT: VÒNG ĐỜI WORKSPACE, CHIA SẺ NHÓM & CƠ CHẾ HỦY LIÊN KẾT (UNLINK)
(Mô hình Serverless Multi-User Sync sử dụng Google Drive API v3 & Google Sheets API v4)
================================================================================

Tài liệu này mô tả chi tiết toàn bộ vòng đời của một không gian làm việc (Workspace) từ lúc Admin tạo/liên kết file, thêm thành viên chia sẻ, đồng bộ dữ liệu hai chiều, cho đến khi Admin thực hiện hủy liên kết (Unlink). Tài liệu bao gồm đầy đủ mô tả logic, quy trình và bộ mã nguồn TypeScript toàn diện để các dự án khác tham khảo và áp dụng.

---

MỤC LỤC:
1. Tổng quan vòng đời Workspace (Lifecycle Overview)
2. Giai đoạn 1: Tạo mới hoặc Liên kết file dữ liệu trung tâm
3. Giai đoạn 2: Thêm thành viên và phân quyền chia sẻ ngầm
4. Giai đoạn 3: Hủy liên kết (Unlink) và thu hồi quyền tự động
5. Giai đoạn 4: Cơ chế phát hiện ngắt kết nối trên thiết bị thành viên
6. Bộ mã nguồn TypeScript hoàn chỉnh (Google Drive & Sheets API Helpers)

================================================================================
PHẦN 1: TỔNG QUAN VÒNG ĐỜI WORKSPACE
================================================================================

Trong mô hình Serverless Multi-User Sync không dùng Backend Database riêng biệt, tệp Google Sheet (hoặc Excel) trên Google Drive của Admin đóng vai trò là "Nguồn sự thật duy nhất" (Single Source of Truth). Mọi thông tin về trạng thái hoạt động, danh sách thành viên và phân quyền đều được ghi nhận trực tiếp vào **tab ẩn `__CONFIG__`** bên trong tệp Google Sheet đó.

---

================================================================================
PHẦN 2: GIAI ĐOẠN 1 - TẠO MỚI HOẶC LIÊN KẾT FILE (CREATE & LINK)
================================================================================

* **Mô tả logic**:
  - Khi Admin bấm "Tạo file mới" hoặc chọn một tệp Google Sheet có sẵn trên Google Drive để làm trung tâm dữ liệu:
    1. Ứng dụng tạo tệp trên Drive hoặc lấy `fileId` của tệp được chọn.
    2. Khởi tạo trạng thái Master Sync State ban đầu với `status: 'active'`, `lastAction: 'create_and_link'`, định danh `adminEmail` là email của Admin hiện tại, và mảng `members` khởi đầu chứa chính Admin đó với vai trò `ADMIN`.
    3. Ghi các thông tin này vào tab ẩn `__CONFIG__` trên Google Sheet.
    4. Lưu con trỏ file cục bộ trên thiết bị của Admin để các phiên làm việc sau tự động nạp lại.

* **Hàm liên quan chính**:
  - `createRealGoogleDriveFile(...)`
  - `setMasterSyncLinked(...)`
  - `saveMasterSyncStateOnDrive(...)`

---

================================================================================
PHẦN 3: GIAI ĐOẠN 2 - THÊM THÀNH VIÊN VÀ PHÂN QUYỀN CHIA SẺ
================================================================================

* **Mô tả logic**:
  - Khi Admin nhập email của thành viên gia đình (ví dụ: Vợ) và chọn vai trò (`EDITOR` hoặc `VIEWER`):
    1. Ứng dụng thêm đối tượng thành viên vào mảng `members` trong trạng thái Master State.
    2. Ghi đè cập nhật lên tab ẩn `__CONFIG__` trong Google Sheet.
    3. Gọi **Google Drive Permissions API v3** (`POST /files/{fileId}/permissions`) để cấp quyền vật lý trên Google Drive:
       - Cấp quyền `writer` nếu vai trò là `EDITOR`.
       - Cấp quyền `reader` nếu vai trò là `VIEWER`.
  - Nhờ vậy, thành viên ngay lập tức nhận được quyền truy cập tệp trên Google Drive cá nhân của họ mà không cần Admin phải thao tác thủ công ngoài trình duyệt Google Drive.

* **Hàm liên quan chính**:
  - `shareFileWithUserEmail(...)`
  - `updateMemberRoleOnDrive(...)`

---

================================================================================
PHẦN 4: GIAI ĐOẠN 3 - HỦY LIÊN KẾT (UNLINK) VÀ THU HỒI QUYỀN
================================================================================

* **Mô tả logic (Điểm cốt lõi về bảo mật)**:
  - Khi Admin bấm nút **"Hủy liên kết" (Unlink Workspace)**:
    1. **Kiểm tra quyền hạn**: Hệ thống xác thực email thực hiện yêu cầu bắt buộc phải trùng khớp với `adminEmail` lưu trong cấu hình. Nếu không phải Admin, lệnh bị từ chối.
    2. **Thu hồi quyền Google Drive**: Duyệt qua toàn bộ danh sách thành viên (`members`) không phải Admin, gọi API `DELETE /files/{fileId}/permissions/{permId}` để xóa sạch quyền truy cập tệp trên Google Drive của tất cả mọi người ngay lập tức.
    3. **Ghi nhận trạng thái "Unlinked" lên Google Sheet**: Ứng dụng ghi đè trạng thái `status: 'unlinked'` và `lastAction: 'unlink'` trực tiếp vào tab ẩn `__CONFIG__` của tệp trên Drive TRƯỚC KHI xóa con trỏ trên máy Admin. Bước này cực kỳ quan trọng để phát tín hiệu ngắt kết nối đến các thiết bị thành viên khác đang online.
    4. **Dọn dẹp thiết bị Admin**: Xóa con trỏ liên kết cục bộ, đưa ứng dụng của Admin trở về trạng thái cá nhân độc lập.

* **Hàm liên quan chính**:
  - `setMasterSyncUnlinked(...)`
  - `revokeFilePermission(...)`

================================================================================
PHẦN 5: GIAI ĐOẠN 4 - CƠ CHẾ ĐỒNG BỘ & TỰ ĐỘNG NGẮT TRÊN THÀNH VIÊN
================================================================================

* **Mô tả logic**:
  - Khi các thành viên (hoặc thiết bị khác của Admin) mở ứng dụng hoặc thực hiện chu kỳ đồng bộ ngầm định kỳ:
    1. Ứng dụng gọi hàm `getMasterSyncStateFromDrive(...)` hoặc `readMasterSyncStateFromGoogleSheet(...)` để đọc trạng thái từ tab ẩn `__CONFIG__` của tệp trung tâm trên Google Drive.
    2. Hệ thống kiểm tra: Nếu phát hiện `masterState.status === 'unlinked'` hoặc `masterState.lastAction === 'unlink'`:
       - **Ngắt kết nối lập tức**: Thiết bị của thành viên nhận diện tệp đã bị Admin hủy liên kết không gian làm việc.
       - **Dọn sạch dữ liệu cục bộ**: Tự động xóa sạch danh sách sổ tiết kiệm và dữ liệu liên kết trên thiết bị thành viên (`setBooks([])`, xóa localStorage, đặt cờ `explicitly_unlinked = true`).
       - **Hiển thị thông báo bảo mật**: Cảnh báo người dùng *"⚡ Thiết bị khác đã hủy liên kết. Đã ngắt kết nối để bảo mật dữ liệu."*

PHẦN 6: BỘ MÃ NGUỒN TYPESCRIPT HOÀN CHỈNH (GOOGLE DRIVE & SHEETS API)
================================================================================

Dưới đây là các hàm trợ giúp toàn diện giao tiếp với Google Drive API v3 và Sheets API v4 (bao gồm Unlink, Sync, Config Tab Management, Permissions):

```typescript
import { MasterSyncState, WorkspaceMember, SavingsBook, SettlementAdjustment } from './types';

/**
 * 1. ĐỌC CẤU HÌNH MASTER & MEMBERS TỪ TAB ẨN __CONFIG__ TRÊN GOOGLE SHEET
 */
export async function readMasterSyncStateFromGoogleSheet(
  accessToken: string,
  fileId: string
): Promise<MasterSyncState | null> {
  try {
    if (!accessToken || !fileId) return null;

    const configRange = '__CONFIG__!A1:B30';
    const res = await fetch(`https://sheets.googleapis.com/v4/spreadsheets/${fileId}/values/${encodeURIComponent(configRange)}`, {
      headers: { Authorization: `Bearer ${accessToken}` },
    });

    if (!res.ok) return null;

    const data = await res.json();
    const rows: any[][] = data.values || [];
    if (rows.length === 0) return null;

    const kvMap = new Map<string, any>();
    let metadataParsed: any = {};

    for (const row of rows) {
      if (row[0] !== undefined) {
        const key = String(row[0]).trim().toLowerCase();
        const val = row[1];
        kvMap.set(key, val);
        if (key === '__metadata_json__' && typeof val === 'string') {
          try {
            metadataParsed = JSON.parse(val) || {};
          } catch {}
        }
      }
    }

    let membersList: WorkspaceMember[] = Array.isArray(metadataParsed.members) ? metadataParsed.members : [];
    const rawMembers = kvMap.get('members json') || kvMap.get('members');
    if (typeof rawMembers === 'string') {
      try {
        const parsed = JSON.parse(rawMembers);
        if (Array.isArray(parsed)) membersList = parsed;
      } catch {}
    }

    return {
      status: metadataParsed.status || kvMap.get('status') || 'active',
      lastAction: metadataParsed.lastAction || kvMap.get('last action') || 'link',
      activeFileId: fileId,
      activeFileName: metadataParsed.activeFileName || kvMap.get('vault name') || '',
      activeFileUrl: metadataParsed.activeFileUrl || `https://docs.google.com/spreadsheets/d/${fileId}/edit`,
      mimeType: 'application/vnd.google-apps.spreadsheet',
      linkedTimestamp: metadataParsed.linkedTimestamp || kvMap.get('linked timestamp') || '',
      adminEmail: metadataParsed.adminEmail || kvMap.get('admin email') || '',
      members: membersList,
      updatedAt: metadataParsed.updatedAt || kvMap.get('updated at') || '',
    };
  } catch (err) {
    console.warn('[Sheet Config] Lỗi đọc tab cấu hình __CONFIG__:', err);
    return null;
  }
}

/**
 * 2. GHI HOẶC CẬP NHẬT TRẠNG THÁI MASTER VÀO TAB ẨN __CONFIG__ TRÊN GOOGLE SHEET
 */
export async function saveMasterSyncStateToGoogleSheet(
  accessToken: string,
  fileId: string,
  state: MasterSyncState
): Promise<boolean> {
  try {
    if (!accessToken || !fileId) return false;

    const nowIso = state.updatedAt || new Date().toISOString();
    const coreMetadataPayload = JSON.stringify({
      schemaVersion: 2,
      status: state.status || 'active',
      lastAction: state.lastAction || 'link',
      activeFileId: fileId,
      activeFileName: state.activeFileName || '',
      activeFileUrl: state.activeFileUrl || `https://docs.google.com/spreadsheets/d/${fileId}/edit`,
      adminEmail: state.adminEmail || '',
      linkedTimestamp: state.linkedTimestamp || '',
      updatedAt: nowIso,
    });

    const values: (string | number)[][] = [
      ['__METADATA_JSON__', coreMetadataPayload],
      ['Vault Name', state.activeFileName || ''],
      ['Admin Email', state.adminEmail || ''],
      ['Status', state.status || 'active'],
      ['Last Action', state.lastAction || 'link'],
      ['Members JSON', JSON.stringify(state.members || [])],
      ['Updated At', nowIso],
    ];

    const batchUrl = `https://sheets.googleapis.com/v4/spreadsheets/${fileId}/values:batchUpdate`;
    const writeData = () => fetch(batchUrl, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        valueInputOption: 'USER_ENTERED',
        data: [{
          range: `__CONFIG__!A1:B${values.length}`,
          majorDimension: 'ROWS',
          values: values,
        }],
      }),
    });

    let res = await writeData();

    // Nếu tab __CONFIG__ chưa tồn tại, tiến hành tạo mới tab rồi ghi lại
    if (!res.ok && res.status === 400) {
      const createRes = await fetch(`https://sheets.googleapis.com/v4/spreadsheets/${fileId}:batchUpdate`, {
        method: 'POST',
        headers: {
          Authorization: `Bearer ${accessToken}`,
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({
          requests: [{
            addSheet: {
              properties: {
                title: '__CONFIG__',
                hidden: false,
                gridProperties: { rowCount: 50, columnCount: 5 },
              },
            },
          }],
        }),
      });

      if (createRes.ok) {
        res = await writeData();
      }
    }

    return res.ok;
  } catch (err) {
    console.warn('[Sheet Config] Lỗi ghi tab cấu hình:', err);
    return false;
  }
}

/**
 * 3. HỦY LIÊN KẾT WORKSPACE (CHỈ ADMIN) - THU HỒI QUYỀN DRIVE & GHI UNLINK LÊN SHEET
 */
export async function setMasterSyncUnlinked(
  accessToken: string,
  userEmail?: string,
  explicitFileId?: string
): Promise<void> {
  try {
    localStorage.setItem('explicitly_unlinked', 'true');
    sessionStorage.setItem('explicitly_unlinked', 'true');

    const targetFileId = explicitFileId || localStorage.getItem('last_linked_file_id_v2');
    if (!targetFileId || !accessToken) return;

    const currentMaster = await readMasterSyncStateFromGoogleSheet(accessToken, targetFileId);

    const adminEmailVal = currentMaster?.adminEmail || currentMaster?.linkedAccountEmail || userEmail || 'admin';
    const cleanUser = userEmail?.trim().toLowerCase();
    const adminEmailClean = adminEmailVal.trim().toLowerCase();

    // Bảo mật: Từ chối nếu không phải Admin
    if (cleanUser && adminEmailClean && cleanUser !== adminEmailClean) {
      console.warn(`[Unlink Security] Tài khoản ${cleanUser} không phải Admin.`);
      return;
    }

    // 1. Thu hồi quyền Google Drive của tất cả thành viên không phải Admin
    if (currentMaster?.members && currentMaster.members.length > 0) {
      for (const member of currentMaster.members) {
        if (member.role !== 'ADMIN' && member.email) {
          await revokeFilePermission(accessToken, targetFileId, member.email).catch(() => {});
        }
      }
    }

    const nowIso = new Date().toISOString();

    // 2. Ghi trạng thái unlinked lên tab ẩn __CONFIG__ của Google Sheet
    const unlinkedSheetState: MasterSyncState = {
      ...(currentMaster || {}),
      status: 'unlinked',
      lastAction: 'unlink',
      activeFileId: targetFileId,
      activeFileName: '',
      activeFileUrl: '',
      linkedTimestamp: nowIso,
      linkedAccountEmail: userEmail || 'Google User',
      adminEmail: adminEmailVal,
      members: currentMaster?.members || [],
      updatedAt: nowIso,
    };

    await saveMasterSyncStateToGoogleSheet(accessToken, targetFileId, unlinkedSheetState).catch(() => {});

    // 3. Dọn dẹp con trỏ cục bộ trên máy Admin
    localStorage.removeItem('last_linked_file_id_v2');
    localStorage.removeItem('master_pointer_file_id');
    localStorage.removeItem('master_sync_state_local_v2');

    console.info('[Unlink] Đã hủy liên kết Workspace thành công.');
  } catch (err) {
    console.warn('Lỗi hệ thống khi Unlink:', err);
    localStorage.removeItem('last_linked_file_id_v2');
  }
}

/**
 * 4. CẤP QUYỀN TRUY CẬP GOOGLE DRIVE CHO THÀNH VIÊN (SHARE FILE)
 */
export async function shareFileWithUserEmail(
  accessToken: string,
  fileId: string,
  userEmail: string,
  role: 'reader' | 'writer'
): Promise<boolean> {
  try {
    if (!fileId || !userEmail) return false;
    const url = `https://www.googleapis.com/drive/v3/files/${fileId}/permissions?sendNotificationEmail=false&supportsAllDrives=true`;
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        role,
        type: 'user',
        emailAddress: userEmail.trim().toLowerCase(),
      }),
    });
    return response.ok;
  } catch (err) {
    console.warn('Lỗi cấp quyền Google Drive:', err);
    return false;
  }
}

/**
 * 5. THU HỒI QUYỀN TRUY CẬP GOOGLE DRIVE CỦA THÀNH VIÊN (REVOKE PERMISSION)
 */
export async function revokeFilePermission(
  accessToken: string,
  fileId: string,
  userEmail: string
): Promise<boolean> {
  try {
    if (!fileId || !userEmail) return false;
    const cleanEmail = userEmail.trim().toLowerCase();

    const listUrl = `https://www.googleapis.com/drive/v3/files/${fileId}/permissions?fields=permissions(id,emailAddress,role,type)`;
    const listRes = await fetch(listUrl, {
      headers: { Authorization: `Bearer ${accessToken}` },
    });
    if (!listRes.ok) return false;

    const data = await listRes.json();
    const permissions: Array<{ id: string; emailAddress?: string; role?: string; type?: string }> = data.permissions || [];

    const userPerm = permissions.find(
      (p) => p.type === 'user' && p.emailAddress?.trim().toLowerCase() === cleanEmail
    );
    if (!userPerm || !userPerm.id) return false;

    const delUrl = `https://www.googleapis.com/drive/v3/files/${fileId}/permissions/${userPerm.id}`;
    const delRes = await fetch(delUrl, {
      method: 'DELETE',
      headers: { Authorization: `Bearer ${accessToken}` },
    });

    return delRes.ok || delRes.status === 204;
  } catch (err) {
    console.warn(`Lỗi thu hồi quyền Drive của ${userEmail}:`, err);
    return false;
  }
}
```
