======================================================================
1. TOM TAT DANH CHO NHOM TIEP NHAN
======================================================================

Day la ung dung desktop Windows viet bang Python va PySide6. Chuc nang chinh la chon
nhieu file PDF/EPUB, phat hien mot so truong hop da la tieng Viet de bo qua, chuyen PDF
digital sang EPUB bang Marker va Pandoc, sau do dich noi dung EPUB sang tieng Viet qua
Gemini. File dau ra thuong nam canh file goc va co hau to "_vietnamese".

Khong nen xem ma Python nay la mot module co the dong goi truc tiep vao APK:
- Giao dien hien tai la Qt/PySide6, khong phai web UI.
- Chuyen PDF dang goi cac executable Marker, Pandoc va co the can llama-server.
- Luong PDF DOCX cu dung pdf2docx, python-docx, docx2pdf/LibreOffice, Tesseract,
  OpenCV va Pillow.
- Gemini client dang nam trong ung dung Python; dua API key vao APK se de bi trich xuat.
- Chua co project Capacitor, package.json, API backend, schema job, migration hay test
  tu dong trong snapshot duoc khao sat.

Huong di de xuat: tach giao dien Capacitor khoi backend xu ly tai lieu. APK chon file,
gui job qua API HTTPS, theo doi tien do, va tai EPUB/PDF dau ra. Backend quan ly Gemini,
cache, tien trinh chuyen doi va file tam. Neu can xu ly hoan toan tren thiet bi, can
thiet ke lai tung kha nang bang Android native/plugin va thu nghiem gioi han RAM, CPU,
storage; khong the mang nguyen Marker/Pandoc/PySide6 vao WebView.

Bao mat can xu ly truoc khi phat hanh: ma nguon hien tai co cac chuoi API key Gemini
duoc khai bao truc tiep trong ai/runtime.py. Tai lieu nay khong sao chep gia tri key.
Can coi cac key da lo la, thu hoi/rotate tren nha cung cap, loai khoi source history va
chuyen sang secret manager/backend. Khong nhung key Gemini vao APK, JS bundle hay
native resource.

3.1. Entry point va giao dien

3.2. AI

ai/runtime.py la diem ghep cac service AI:
- Tao APIKeyManager va GeminiTranslateService singleton.
- Goi translate_text_with_gemini va goi OCR anh theo lo.
- Chia se key_manager cho EPUB va PDF.

ai/gemini_manager.py:
- Luu state theo tung key/model: request times, daily count, cooldown.
- Chon key theo round-robin, gioi han RPM/RPD noi bo, doi khi het gioi han cua so

- Goi Google GenAI generate_content; thu lan luot model va key; tra (text, error).
- Nhan dien quota/rate-limit de cooldown va retry.
- RPM/RPD trong bo nho chi ton tai trong mot lan chay; khong phai bo dem quota chuan
  cua nha cung cap va khong dong bo giua nhieu instance.

ai/gemini_translate.py:
- Tao prompt theo the loai/temperature, yeu cau ket qua co nhan [P_i].
- Retry voi safety context khi lan dau khong co ket qua.
- Batch dich EPUB duoc parse thanh map chi so -> chuoi dich.
- Neu map khong hop le: thu lai, giu cac muc dung trong response partial, dich lai
  muc thieu, hoac chia batch thanh nua.
- Chay cac chunk song song; toi da 4 worker va thu hep theo so key.
- Chunk nao con thieu ket qua thi fallback giu nguyen van ban goc cho doan thieu,
  ghi canh bao va van ghi cache. Do do "job thanh cong" khong tu dong co nghia la
  moi doan da duoc dich; can co trang thai loi/partial trong san pham moi.

ai/gemini_ocr.py:
- Tien xu ly anh bang Pillow, tuy chon OpenCV/Otsu, resize toi da canh 1600 px.
- OCR local Tesseract voi cac PSM 6/11/4, tinh confidence va kiem tra dau hieu
  tieng Viet.
- Gate anh theo hinh hoc/diem anh va diem hinh anh co text; nguong chon anh 0.42.
- Nguong confidence OCR mac dinh 48; batch Gemini mac dinh 3 anh.
- OCR gate co cac ly do nhu anh nho/khong duoc chon, dependency thieu, khong co chu,
  da la tieng Viet, confidence thap.
- Module nay duoc goi boi pdf/workflow; luong PDF chinh tu giao dien khong goi OCR.

3.3. EPUB

epub/workflow.py::process_epub_file:
1. Tao cache theo ten file EPUB va tao metadata fingerprint.
2. Doc EPUB bang EbookLib; lay cac item document va parse HTML bang BeautifulSoup.
3. Chon cac leaf block trong p/h1-h6/li/td/th/dt/dd co text; bo qua node cha neu
   chua block con de tranh dich lap.
4. Chia batch theo uoc tinh don vi, dich song song, ghi cache tung chunk.
5. Nap map dich vao node; khoi phuc HTML markup da duoc thay bang token.
6. Ghi lai noi dung XHTML.
7. Dich title trong TOC theo batch toi da 40 entry; cap nhat link.title.
8. Ghi <ten>_vietnamese.epub; xoa cache sau khi ghi thanh cong.

epub/markup.py:
- protect_epub_markup thay cac tag con bang __HTML_TAG_n__.
- parse_translation_map yeu cau dung du nhan, khong trung chi so va bao toan token.
- restore_epub_markup dua tag goc tro lai sau dich.
- Neu token khong duoc tra ve, ham khoi phuc tra False; caller hien tai van khong
  danh dau ro ket qua chunk thanh loi tai diem goi.

Tham so enable_ocr trong process_epub_file khong duoc su dung trong than ham; workflow
EPUB khong thuc hien OCR anh. OCR anh khong duoc bat boi luong giao dien chinh.

3.4. PDF va chuyen doi

Luong duoc giao dien goi (Dich_sach_AI_v1.1.py):
- PDF duoc phan loai scan/digital bang PyMuPDF.
- Neu PDF scan: bo qua.
- Neu PDF digital: Marker chuyen PDF thanh Markdown; Pandoc chuyen Markdown thanh
  EPUB3; EPUB duoc kiem tra co dau hieu tieng Viet; neu chua co thi chay EPUB workflow.
- Intermediate EPUB co hau to _marker duoc doi ten thanh _vietnamese neu da la tieng
  Viet, hoac bi xoa sau khi dich xong.
- OCR Marker bi tat bang --disable_ocr; pipeline co buoc phuc hoi anh PDF bi bo sot va
  ghep mot so hinh phuc tap thanh anh, nhung khong OCR chu trong anh.

Marker/Pandoc trong convert/marker_pandoc_pipeline.py:
- Tim executable tu PATH, thu muc tools, Python Scripts, .venv va mot so vi tri Windows.
- Marker chay marker_single, mac dinh mode fast, disable multiprocessing, disable OCR,
  tat PDF text reading order theo tham so hien tai.
- Theo doi output subprocess, cap nhat tien do trang, timeout duoc tinh theo so trang
  va kich thuoc PDF, gioi han 300-600 giay.
- Xu ly Markdown: xoa synthetic title, chuan hoa khoang trang, copy tai nguyen anh.
- Restore anh PDF khong duoc Marker tham chieu; render mot so hinh co overlay text/
  vector thanh composite image.
- Pandoc tao EPUB3 voi CSS co ban, resource-path va split-level 1.
- Sau do hop cac XHTML content document vao luong doc lien tuc, cap nhat manifest/
  spine/TOC va tao EPUB moi.
- Cleanup Markdown, assets va thu muc output Marker khi thanh cong.

Luong PDF rieng (pdf/workflow.py va pdf/document_tools.py):
- process_pdf_text_file chuyen PDF text sang DOCX bang pdf2docx.
- Don dep mot so style/bang/hinh, co the phuc hoi anh PDF.
- Neu enable_ocr=True, loc anh qua OCR local roi gui anh dat dieu kien sang Gemini;
  chen ban dich vao DOCX.
- Gom cac paragraph, bo header/footer va chu da OCR, chia batch/dich, ghi text vao
  DOCX, chuyen thanh PDF bang docx2pdf hoac LibreOffice fallback.
- Co buoc xoa trang trong/trang chi co header-footer.
- Dung cache pdf_text rieng.
- Ham nay goi validate_runtime_environment() ngay dau, yeu cau stack OCR/EPUB/PDF

Quan trong: khong thay thay loi goi process_pdf_text_file hoac module pdf.workflow
tu entry point UI. Day la luong rieng/legacy trong snapshot, khong phai luong PDF ma

5. DATA FLOW / CONTRACT GOI Y
======================================================================

Data flow hien tai:
Nguoi dung -> Qt file picker -> danh sach Path -> BookWorker/QThread
  -> phan loai PDF/EPUB
  -> (PDF digital) Marker -> Markdown + assets -> Pandoc -> EPUB
  -> EPUB parse HTML -> leaf text nodes -> [P_i] prompt -> Gemini
  -> parse/validate response -> cache chunk -> restore HTML -> write EPUB
  -> file ket qua trong output directory -> UI thong bao.

Data flow de xuat cho Capacitor:
Capacitor UI -> Android document picker (URI)
  -> POST /v1/jobs (multipart upload hoac signed upload)
  -> backend tao job + validate file + luu object tam
  -> worker doc/phan loai/chuyen doi/dich
  -> database job state + object storage result/cache
  -> GET /v1/jobs/{id} hoac WebSocket/SSE de cap nhat
  -> GET /v1/jobs/{id}/result download.

API contract toi thieu:
- POST /v1/jobs
  Input: file, languageTarget="vi", styleId, options (co the bo qua scan, xu ly OCR,
  output format), idempotencyKey.
  Output: jobId, state="queued", createdAt.
- GET /v1/jobs/{jobId}
  Output: state, stage, progressPercent, currentFile, currentChunk, totalChunks,
  warnings[], error {code,message,retryable}, result {name,size,downloadUrl}.
- POST /v1/jobs/{jobId}/cancel (neu backend ho tro huy).
- GET /v1/jobs/{jobId}/result: tai file dau ra sau khi job completed.
- POST /v1/jobs/{jobId}/retry: tiep tuc tu cache/checkpoint neu retryable.

Trang thai nen co:
queued -> validating -> classifying -> converting -> extracting -> translating ->
packaging -> completed.
Nhanh khac: skipped (scan/already Vietnamese), partial (co doan giu nguyen), failed,
cancelled. Khong tra "completed" neu bat ky chunk nao duoc fallback sang text goc ma
khong hien warning ro rang cho nguoi dung.

Job record goi y:
job_id, owner_id, source_name, source_sha256, source_size, mime_type, source_format,
detected_document_type, target_language, style_id, options_json, state, stage,
progress, warning_count, error_code, result_object_key, created_at, updated_at,
expires_at.
Khong luu API key trong record/job/client. Cache phai co owner scope, TTL, encryption
at rest neu chua tai lieu la tai san rieng tu.

Don vi job:
- Mot file = mot job de co the retry/huy/bao loi doc lap.
- UI co the gui nhieu file nhung tao nhieu job; hien thi queue/concurrency co gioi han.
- Giu idempotency key de tranh upload va dich lap khi mobile mat mang gui lai request.

8. KIEN TRUC DE XUAT CHO SAN PHAM CAPACITOR
======================================================================

Frontend:
- Capacitor + web framework da chon (React/Vue/Angular).
- Screens: Library/Select files, Job queue, Job detail, Settings/privacy, Result preview.
- Service: upload client, job polling/SSE, retry/cancel, secure session storage.
- Native plugins: document picker, filesystem, download/share, background transfer.
- Khong nhung ma Python hoac Gemini credential trong bundle.

Backend API:
- Auth/session va authorization theo user.
- Validate upload, tao job, job status, cancel/retry, download result.
- Rate limit theo user va source IP; gioi han so job dong thoi va chi phi model.
- Secret Gemini chi tren server; log redact; metrics va audit.

Worker:
- Queue (Redis/RQ, Celery, cloud queue hoac tuong duong).
- Worker Python co the tai su dung mot phan module hien tai.
- Chay conversion trong container/image co pin version Marker/Pandoc va dependency.
- Tach worker EPUB-only va PDF conversion neu tai nguyen/timeout khac nhau.
- Ghi stage/progress vao database, artifact vao object storage, cleanup theo TTL.
- Idempotency theo user + source hash + options/prompt version.

Service seams nen tach:
1. DocumentInspector: verify, format, page/chapter count, scan/language heuristic.
2. PdfToEpubConverter: PDF digital -> Markdown -> EPUB; progress va timeout ro rang.
3. EpubExtractor: chapter/block ID + text + markup tokens.
4. TranslationProvider: Gemini backend abstraction, structured response, quotas.
5. TranslationJob: chunk checkpoint, retry, partial status, cancellation.
6. EpubWriter/PdfWriter: ghi output, verify artifact.
7. JobRepository/ArtifactStore: state, cache, ownership, retention.
